# Vital’nya scrollytelling: Oekraïne (V22 review)

`oekraine.html` is a new, bilingual, interactive story page. All six original composite images are preserved as optimized WebP assets in `assets/ukraine/`.

The first three widescreen collages assemble from masked visual zones as the user scrolls. The three portrait collages are vertically panned with synchronised short notes. On narrow screens, widescreen collages become three larger cropped reveal panels. Controls include language switch, chapter dots and menu. The page supports `prefers-reduced-motion`.

Open `oekraine.html` from a **local web server** (such as `python -m http.server`) or deploy the entire ZIP contents as the GitHub Pages repository root. The other site pages have new navigation links to `oekraine.html`. All pre-existing pages and assets are retained.

**Editorial warning:** All six composites have already been flattened into a single image per scene. Consequently, this page animates masked regions of the composites, rather than individually reconstructing the original source photographs. For completely independently moving photographs, supply the licensed original assets and photo credits. These composites are illustrative interpretations; do not describe them as verified news photographs. Text embedded inside the composites is predominantly Dutch and cannot be translated by the language switch.
