# Vital’nya — V23 Full-Bleed Oekraïne page

This iteration changes only `oekraine.html`. It removes the centered picture frames, uses viewport-width collages, and keeps the existing six-scene scroll-driven narrative.

## Deployment
Upload `oekraine.html` to your current `vitalnya-preview` repository, replacing the previous file. No new assets are required if V22 assets are already deployed. Otherwise use the complete ZIP, which includes every asset.

## Important editorial note
The supplied scene collages are artistic composites, NOT verified standalone photographs of real events. For publication, verify original photograph permissions, accurate dates/contexts, and appropriate credits, replacing composites where necessary.
